# 必要な後退 — 単位を視認限界の下へ置いた一枚の大判プリント

遠くで像が立ち、近づくと像が失われる構造を、単位の物理寸法によって成立させる大判プリントの制作計画です。

## このプランで見るもの

壁面から約4メートル離れた位置では像が立ち、腕が届く距離まで近づくと単位だけが残って像がほどける。一枚の面を往復することで、理解できる距離と介入できる距離が一致しないことを体験します。

**主張:** 近さは理解も介入も保証しない。像が立つのは離れたときであり、そこでは手が届きません。

**発想の由来:** 距離で像が変わる作品と、近いのに介入できない作品を別々の仕組みにせず、単位の物理寸法という一つの決定で同時に成立させる発想です。計画では、上海派の造形操作を様式名ではなく輪郭と彩度の扱いとして参照しています。

**素材・形式:** 300 dpiの実寸原版を用いた一枚の大判プリントです。単位の目標寸法は1辺1.1853 mmで、印刷方式と用紙は実寸の試し刷りで検証する前提です。

**固有の構成:** 1辺1.1853 mmの単位を視認限界の下へ置き、単位の物理寸法だけで、遠景の像と近接時の消失を同時に成立させる大判プリントです。柵・禁止表示・監視による介入制御は作品の仕組みに含めません。

## 制作への入口

まず `plan.md` の制作範囲と未解決事項を読み、300 dpiの実寸原版から実寸の試し刷りを一枚出力します。壁面から約4メートルの成立距離と腕が届く近接距離で観察し、単位が形として読めないこと、成立距離で像が立つこと、介入不能が規則ではなく寸法から生じることを記録します。現在は物理試作前の計画段階であり、このProject公開物は印刷物の完成や購入・展示の実施記録ではありません。

![必要な後退 — 遠景の見本](media/sample-whole.jpg)

遠景の見本です。実寸 1527.9 × 1018.2 mm の印刷原版を 1625 px 幅へ縮小しています。計画の完成像は、壁面から4メートル前後で像が立つことを条件にしています。

![単位の原寸部分](media/sample-detail.jpg)

同じ画面の原寸部分です。300 dpi のまま切り出しており、1辺 1.1853 mm の単位が約 118 × 79 個入ります。この距離では像が読めません。近づくと像が失われる構造は、単位の物理寸法だけで成立しています。

いずれも印刷原版からのレンダリングであり、印刷した現物の写真ではありません。
