# 必要な後退 — 単位を視認限界の下へ置いた一枚の大判プリント

> `agentic-art-orchestration` が生成した制作計画を、作品の仮説、技術条件、受入条件に限定して公開します。内部handoff、研究台帳、実行ログ、原寸データ、RAW、大容量素材は含めません。

## 作品の核

遠くから壁一面の像が見えて、何が描かれているか分かる。近づくにつれて像がほどけ、単位が形として読めないまま面だけが残る。手を伸ばせる距離まで来ても、像はもうそこにない。

## 鑑賞者の経験

1. 壁面から約4.07メートル離れた位置で、像が一つのまとまりとして立つ。
2. 近づくにつれて、像が暖色と寒色の別々の単位へほどける。
3. 腕が届く位置まで来ると像は消え、鑑賞者は、像が立つ距離では物理的に触れられないことに気づく。

作品が成立する距離と、介入できる距離を同じにしない。介入不能は柵や禁止表示ではなく、単位の物理寸法によって成立させる。

## テーマとメッセージ

知覚の距離と、介入可能性の分離を扱う。近づけば分かる、近づけば関与できる、という前提に対して、距離を詰めるほど像が失われる経験で応答する。

> 近さは理解も介入も保証しない。像が立つのは離れたときであり、そこでは手が届かない。

説明で結論を補うのではなく、鑑賞者が自分で近づいて像を失うことを成立条件とする。

## 技術仮説

分割された単位の寸法を鑑賞距離から逆算し、混色を画面上の処理ではなく鑑賞者の網膜上の合成として起こす。計画上の初期条件は次のとおりである。

| 項目 | 初期条件 |
| --- | --- |
| 画面 | 長辺約1528mmの大判プリントを想定する。 |
| 成立距離 | 約4.07mを起点に、実寸試し刷りで再評価する。 |
| 単位 | 約1.1853mmを起点に、紙・印刷方式・視認条件と合わせて検証する。 |
| 近接位置 | 腕が届く位置で、単位が形として読めず像が失われることを確認する。 |
| 媒体 | 拡大縮小をしない実寸の試し刷りから始める。 |

数値は完成結果ではなく、受入試験のための仮説条件である。

## 必須要件と受入試験

| 要件 | 受入試験 | 合格条件 |
| --- | --- | --- |
| 単位が近接視で形として読めない。 | 実寸試し刷りの近接観察 | 近接で単位が独立した形として読めない。 |
| 作品側が成立距離を指定し、その距離で像が立つ。 | 成立距離と近接位置の比較 | 指定距離で像が立ち、近づくと像が失われる。 |
| 介入不能が物理寸法によって成立する。 | 設置・構造レビュー | 柵・監視・禁止表示を使わず、成立距離では手が届かない。 |
| 参照した造形操作と権利区分を追跡できる。 | 操作・出典・権利の突合 | 採用操作から公開出典と利用範囲まで追跡できる。 |

受入試験は未実施である。制作物が未検証の段階で、成立済みとは扱わない。

## 工程

1. 300dpiの実寸原版から、実寸の試し刷りを一枚出力する。
2. 近接位置と成立距離の二位置で観察し、単位の読解と像の成立を記録する。
3. 設置計画から、介入を止めている要素を列挙し、規則や柵ではなく寸法由来であることを確認する。
4. 造形操作、公開出典、権利区分を突合し、欠落があれば制作計画を再評価する。

実寸印刷、購入、会場設営、契約、展示、外部共有は、それぞれの条件を確認した人間の承認後に行う。

## 未解決事項

- 単位が紙の上で分離するかは、実寸の試し刷りでしか確かめられない。
- 二次資料の独立性、原典の確認、参照操作の位置づけは追加レビューが必要である。
- 紙、印刷方式、固定、照明、会場動線、安全、アクセシビリティは未確定である。
- 作品を公開設置する場合の素材権利と会場許可は別途確認する。

## 権利・プライバシーの境界

- 先行作品の画像、映像、長文、完成データを制作素材や公開資料へ転載しない。
- 個人原資料、顔、声、会話全文、認証情報、ローカルパスは扱わない。
- 公開版では、参照作品の名称と公開ページへのリンク、そこからの差分説明だけを用いる。
- 実寸原版、印刷データ、RAW、動画、音声、3D、大容量素材はこの計画レコードに含めない。
