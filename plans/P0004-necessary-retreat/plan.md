## 1. 完成像

| 項目 | 内容 |
| --- | --- |
| experience sequence / encounter | 遠くから壁一面の像が見えて、何が描かれているか分かる, 近づくにつれて像がほどけ、単位が形として読めないまま面だけが残る, 手を伸ばせる距離まで来ても、像はもうそこに無い |
| position | 壁面から4メートル前後の位置と、腕が届く位置の二か所を鑑賞者が自分で往復する |
| first_seconds | 最初の数秒は、遠景で像が立っていることだけが分かる |
| after_30s | 30秒ほどで、近づくと像が消えることに気づき、距離を測り直しはじめる |
| after_3min | 3分ほどで、像が立つ位置は自分の身体が決めていて、そこでは触れないという構造に行き当たる |

## 2. テーマ

| 項目 | 内容 |
| --- | --- |
| field | 知覚の距離と、介入可能性の分離 |
| stands_against | 近づけば分かる、近づけば関与できる、という前提に反対する |
| difference | 距離で像が変わる作品と、近いのに介入できない作品は別々に存在してきたが、両方を単位の物理寸法という一つの決定で同時に成立させる |
| why_now | 広告表示が分かる形になっているかを各国が問いはじめ、近さと分かることの関係が制度の問題になっている |

| who_disagrees | 近づくほど対象を把握でき、関与できるはずだと考える人 |

| shown_not_told | 説明ではなく、鑑賞者が自分で近づいて像を失うという経験で示す |
