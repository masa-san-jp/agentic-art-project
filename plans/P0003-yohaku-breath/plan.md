## 1. 完成像

| 項目 | 内容 |
| --- | --- |
| experience sequence / encounter | 鑑賞者は入り口付近から作品全体を見渡せる位置に立つ。, 近づくと部分の細部は見えるが、全体の構成は視野から外れていく。, 位置を変え直したとき、最初の立ち位置が唯一の見方ではなかったと遡って気づく。 |
| position | 鑑賞者は固定された導線を持たず、空間内を自由に移動しながら距離と角度を選ぶ。 |
| first_seconds | 最初の数秒で、近づくほど細部が、離れるほど全体が見えるという対応関係に気づく。 |
| after_30s | 30秒後には、少なくとも一度、最初の立ち位置から動いて別の見え方を確かめている。 |
| after_3min | 3分後には、最初の立ち位置が唯一の選択ではなかったことを、自分の移動によって理解している。 |
