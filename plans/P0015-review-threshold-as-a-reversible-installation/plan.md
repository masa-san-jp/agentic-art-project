## 1. 完成像

| 項目 | 内容 |
| --- | --- |
| experience sequence / encounter | 入ってきた人は、説明のない中立的な要素の関係を目で追う。, ひとつの閾値で関係が変わり、そこから前の配置を見直す。, 見直しによって、最初は背景だった規則が自分の経験として立ち上がる。 |
| position | 鑑賞者は一つの短い経路を歩き、閾値の前後で視点を戻せる。 |
| first_seconds | 最初の数秒で、要素の反復と経路の単純さが分かる。 |
| after_30s | 30秒後には、ひとつの関係変化を見つけ、前の状態を見直し始める。 |
| after_3min | 3分後には、レビューの行為が規則を知覚させたと残る。 |

## 2. テーマ

| 項目 | 内容 |
| --- | --- |
| field | レビューによって初めて見える関係 |
| stands_against | 説明や予測を先に与えれば理解できるという見方に対して立つ。 |
| difference | レビューを画面上の機能や個人資料ではなく、鑑賞者の身体位置と可逆的な関係変化として置く。 |
| why_now | emerging trendは記録されているが、予測はpendingで有効期限も過ぎているため、現在の条件と未来の主張を切り分ける必要がある。 |

## 3. メッセージ

| 項目 | 内容 |
| --- | --- |
| claim | 関係は、見直すきっかけが生じたときに初めて、見えていたものとして知覚される。 |
| who_disagrees | 関係は説明や一覧だけで十分に伝わり、鑑賞者の位置変化は不要だと考える設計者。 |
| denies | 生の個人資料の公開や、トレンドの将来予測が作品の具体性を保証するという前提を否定する。 |
| shown_not_told | 壁面の説明を足さず、ひとつの閾値と鑑賞者の戻る動きで示す。 |
