# 移動する空白 — Moving Gap

異なる記号系を載せた二層の面をずらして重ね、二方向からの接近で異なる読解を生む。中央の隙間は接触や融合を許さない。

## このプランで見るもの

二つの進入方向を移動し、片側ずつ読みやすくなる記号と中央の局所的な隙間を比較する。

**主張:** 近づくと知識は増えるが、近づいた者が相手の形式を動かせるとは限らない。

**固有の構成:** 二層の平面、二方向の接近経路、非接触の停止点。異なる伝統を一つに均質化しない。
