## 1. 完成像

| 項目 | 内容 |
| --- | --- |
| experience sequence / encounter | 鑑賞者は二つの異なる方向の入口から、層状の平面または枠のあいだへ近づく。, 近づいて横切るにつれて、重なっていた関係の一部と局所的な隙間が別の順序で現れる。, 立ち止まる、ゆっくり進む、または座って見るという選択を経て、近さと介入可能性が一致しないまま退出する。 |
| position | 層状の平面から少し離れた位置を起点とし、二方向から接近できる。会場が許せば、車椅子等を含む低速・着座の観察位置を設ける。 |
| first_seconds | まず近接した二つの面が一つの連続した関係に見えるが、完全には読み切れない。 |
| after_30s | 移動によって見える部分と隠れる部分の順序が変わり、中央または局所の隙間が一箇所の不一致として残る。 |
| after_3min | 鑑賞者は、異なる伝統の交換を単一の系譜として確定できず、距離を縮めても他者や対象を操作できるわけではないことを経験として保持する。 |
