# 移動する隙間による近接場の交換

> `agentic-art-orchestration` が生成した制作計画を、公開対象のコンセプトと検証条件に限定して整理したものです。内部research、handoff、実行ログ、会話、認証情報は含めません。

## 作品の核

異なる伝統のあいだにある交換を、薄い平面または枠の層、二方向の接近経路、局所的な隙間、停止点の組合せへ変換する。鑑賞者の位置が変わると関係の一部だけが現れ、接近しても正面から全体を掌握できない。

ここで扱う関係は、丸山派と四条派を一つの均質な流派としてまとめるものではなく、別々の伝統のあいだにある限定された交換として扱う。

## 鑑賞者の経験

1. 少し離れた位置から、二つの面が一つの連続した関係に見えるが、完全には読み切れない。
2. 二方向のいずれかから近づき、横切ると、見える部分と隠れる部分の順序が変わる。
3. 中央または局所の隙間が、一箇所の不一致として残る。近さは知識を増やすが、介入可能性を保証しない。

会場が許す範囲で、低速または着座の観察位置を設ける。接触や強制的な演技は要求しない。

## テーマとメッセージ

この作品は、複数の伝統を一つの系譜へ還元し、近さを介入や所有の権利と同一視する見方に対抗する。

> 近づけば知識の一部は増えるが、近さは介入可能性を保証しない。

歴史的な関係を説明文で断定するのではなく、二方向の移動によって同じ対象が部分的に開示され、別の部分が遮られる状態を身体で確かめる。

## 造形・体験の仕様

| 項目 | 仕様 |
| --- | --- |
| 媒体 | 可逆的な低コスト模型から始めるインスタレーション。 |
| 構成 | 層状の平面または枠、二方向の接近経路、局所的な隙間、停止点。 |
| 見え方 | 二方向から見え方が変わり、全体を一つの正面図へ回収しない。 |
| アクセス | 接触や強制的な演技なしに鑑賞でき、会場条件に応じて低速・着座の経路を検討する。 |
| 禁止 | 先行作品の裸体の演者、霧、照明演出、鏡、遅延CCTV、直接的な再演を作品内容にしない。 |

## 必須要件と受入試験

| 要件 | 受入試験 | 合格条件 |
| --- | --- | --- |
| 二方向からの移動で、反復する関係と未解決の隙間を観察できる。 | 模型の初見・移動後の比較 | 両方向で移動前後の関係が同一にならず、局所的な隙間が記録される。 |
| 歴史的な関係を限定された交換として示す。 | ラベルと短い説明のレビュー | 丸山派と四条派を一つの均質な流派と断定しない。 |
| 接触や強制的な演技なしに鑑賞できる。 | 低速・着座経路の確認 | 観察者が入り、停止し、退出できる。参加者検証を行う場合は同意とアクセス条件を別に記録する。 |
| 参照した先行作品を複製しない。 | 差分レビュー | 参照作品の固有の身体、霧、鏡、CCTV、照明演出を機構として要求しない。 |

受入試験は実寸模型と会場条件が揃うまで未実施であり、公開レコードはこの未確定性を隠さない。

## 工程

1. 層状の平面を紙、板、その他の低コスト材料で可逆的な模型にする。
2. 二つの接近方向と、一つの着座または低速観察経路を設ける。
3. 初見、移動、停止、退出で何が見えるかを記録する。
4. 歴史的な説明、参照作品との差分、権利、安全、会場許可を確認する。

外部制作や公開設置へ進む前に、材料の権利、構造安全、会場許可、参加者の同意とアクセス条件を人間が確認する。

## 未解決事項

- 実寸で隙間が成立するか、二方向から非対称な見え方になるか。
- 説明文なしでも、別々の伝統の境界を保てるか。
- 実参加者の受け取り方とアクセス条件を、集計属性から推測せずに確認できるか。
- 参照資料の権利・利用範囲と会場条件を最終確定できるか。
