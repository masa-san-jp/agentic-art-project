# 近接不在 — Near, Not Received

> `agentic-art-orchestration` が生成した制作計画を、公開可能な制作仮説・技術条件・受入条件に限定して整理した公開版です。内部handoff、研究台帳、実行ログ、会話、個人由来の原資料、ローカルパス、第三者の画像・文章本文は含めません。

## 作品の核

鑑賞者は透明面のすぐ前に立ち、向こう側に整然と並ぶパケットを見る。手を伸ばせそうな近さでありながら、パケットは受領できない。ひとつの空きと、反復する状態語と、ゆっくりずれる影が、距離を解決ではなく継続する条件として残す。

本作は配送の再演ではない。実際の荷物、住所、追跡番号、配送記録、実在の受取人を使わず、配送に似た状態の並びを、近接と非介入を考えるための新規の形式へ閉じる。

## 鑑賞者の経験

1. 観客は、透明面の向こうに反復するパケットと状態カードを見つける。
2. 見える距離と、手が届く距離が一致しないことに気づく。
3. ひとつの空きと、状態の反復により、到達不能が一度の失敗ではなく持続する条件として読まれる。
4. 低電圧の暖色光と影のずれが、説明なしに時間の中断をつくる。

## テーマとメッセージ

テーマは「近さは受領や介入を保証しない」です。距離を縮めれば問題に触れられるという直感に対し、見ること、近づくこと、受け取ることを別々に設計します。

> 近くにいることは、届いたことでも、介入できたことでもない。

Harlem Renaissance と Négritude の関係は、運動や人物を表象するためではなく、事実と本提案の推論を分ける小さな文脈カードとしてのみ扱います。詩の引用、運動の図像的代用、制作者の代表 claim は用いません。

## 採択した制作方式

透明なパネルの向こうへ、36個のオリジナル手作りパケットを配置します。ひとつの空き、9枚の状態カード、見えるが手の届かない位置、低電圧照明による時間的な影のずれを組み合わせます。状態カードの語は本作のために新規作成し、実際の配送制度の表示を複製しません。

P0005が「見る側に属する枠」を、P0006が「近さと非接触の停止線」を主な操作にしているのに対し、本作はパケットの反復、受領状態の列、ひとつの欠落を中心に据えます。配送を現実へ戻すのではなく、作品内部の状態遷移へ閉じる点を差分とします。

## 技術仮説

| 項目 | 初期条件 |
| --- | --- |
| 透明面 | 幅1.8〜2.4m、約2.1m高。縮尺と素材は試作で再評価する |
| パケット | オリジナル手作りパケット36個。ひとつの空きと、見えるが手の届かない配置を含める |
| 状態カード | ATTEMPT、ARRIVED、NOT RECEIVED などの新規状態語を9枚に反復する |
| 時間 | ひとつの中断または空欄を含む反復。低電圧の暖色光と影のずれを使う |
| 導線 | 観客の通路を約1.2m確保し、パケットの扱いを要求しない |

数値と素材は完成結果ではなく、試作と受入試験で再評価する初期条件です。

## 制作工程

1. 1:10の段ボールと透明板の試作を作り、9個のパケット、ひとつの空き、状態カード、固定した低電圧光を配置する。
2. 三つの観覧位置から、近さ・視認性・接触不能・中断の読みを記録する。
3. 説明なしの観察と短い文脈カード付きの観察を比較する。
4. 歴史カード、可視テキスト、素材の権利、安全、導線を人間が確認する。
5. 条件に届かなければ既存本文を上書きせず、差分と再計画を記録する。

実寸制作、購入、会場設営、契約、展示、外部サービスへの送信は、条件確認と人間承認の後に別途判断します。
