# 近接不在 — Near, Not Received

見える距離と、受領できる距離を切り分ける、個人制作向けの完成保証型プランです。A3サイズの透明な卓上オブジェに、35個の手作りパケット、ひとつの空セル、9枚の状態カード、暖色LED、固定した影板を収めます。

- [メタデータ](metadata.yaml)
- [パケットテンプレート](media/packet-template.svg)
- [配置テンプレート](media/layout-template.svg)

本文には、材料と代替、工具、費用上限、10時間の工程、組立寸法、状態カードの文面、修正範囲、A1〜A9の受入試験を固定しています。実物の制作、公開許可、展示・販売の成立を示すものではありません。
