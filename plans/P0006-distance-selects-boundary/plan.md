# 距離が選ぶ境界 — 近づいても触れない休止の場

> `agentic-art-orchestration` が生成した制作計画を、公開可能な制作仮説・技術条件・受入条件に限定して整理した公開版です。内部handoff、研究台帳、実行ログ、会話、個人由来の原資料、ローカルパス、第三者の画像・文章本文は含めません。

## 作品の核

鑑賞者は停止線の手前から透明面の向こうにある線画を見る。近づくほど細部は見えるが、透明面によって手は作品面へ届かない。見ることと触れることを分離し、鑑賞者の身体距離そのものを作品の構成要素にする。

## 鑑賞者の経験

1. 入場者は、透明面の向こうにある4枚以上の線画パネルを見つける。
2. 近づいても作品面には触れられず、視線だけが境界を越える。
3. 低照度の暖色光が緩やかに変化し、10秒以上の静止区間で、作品と自分の距離へ注意が戻る。

作品は、鑑賞者を記録したり健康状態を判定したりしません。カメラ、マイク、生体センサー、睡眠・健康データは使用しない設計です。

## テーマとメッセージ

休止や睡眠が測定・管理される現在において、休むことを効果や数値として提示せず、介入しない時間として扱います。

> 近さは、理解も介入も保証しない。見える距離と、触れられる距離は別に設計できる。

## 技術仮説

| 項目 | 初期条件 |
| --- | --- |
| 透明面 | 幅1800mm × 高さ2100mmを基準とする透明ポリカーボネート面 |
| 鑑賞位置 | 作品面から450mm以上手前の停止線 |
| 線画 | 4枚以上。歪んだ輪郭、平坦な面、非自然的な低彩度色を用いる |
| 光 | 低照度の暖色光。30秒周期で緩やかに変化し、10秒以上の静止区間を置く |
| 導線 | 幅1200mm以上。停止線を越えずに全体を視認できること |

数値は完成結果ではなく、試作と受入試験で再評価するための初期条件です。

## ビジュアル方針

線画は表現主義の既存作品や図像を直接引用せず、内的経験を歪み、平坦化、非自然色、線の反復へ翻訳します。公開用のリファレンスボードは、外部画像を転載せず、参照先へのリンクと設計上の差分だけを示します。

## 必須要件と受入試験

| 要件 | 受入試験 | 合格条件 |
| --- | --- | --- |
| 見える距離と触れられる距離を分ける | 寸法・視認レビュー | 停止線の手前から全線画を視認でき、手が作品面へ届かない |
| 線画を4枚以上用いる | ビジュアルレビュー | 既存作品の図像転載がなく、歪んだ輪郭・平坦な面・低彩度の非自然色が確認できる |
| 休止を数値化せず光の静止区間で示す | 時間・表示レビュー | 30秒周期と10秒以上の静止区間を確認でき、健康・睡眠の数値や診断表現がない |
| 安全な鑑賞導線を確保する | 導線・接触レビュー | 幅1200mm以上、角の処理、接触なしの鑑賞、停止線手前からの視認を確認できる |
| 個人情報と第三者素材を使わない | プライバシー・権利レビュー | センサー、健康データ、実在人物の肖像、第三者素材の無断転載が0件である |

## 制作工程

1. 透明面、停止線、4枚以上の線画、低照度の暖色光を一面の試作として組む。
2. 停止線の手前と近接位置で、視認性・接触不能・身体距離の変化を記録する。
3. 説明なしと短い説明カード付きの鑑賞を比較し、健康効果の説明へ誤読されない文言を検討する。
4. 会場条件、角の処理、導線幅、照明周期、素材の権利状態を確認し、必要なら計画を改訂する。

実寸制作、購入、会場設営、契約、展示、外部サービスへの送信は、各条件を確認したうえで別途判断します。

## 未解決事項

- 会場照明と観客密度が、透明面・停止線・線画の見え方へ与える影響。
- 休止の反復が、健康効果や自己管理の推奨として誤読されない表示方法。
- 透明面、木枠、照明、線画パネルの数量・調達・安全状態。
- 実寸試作での視認性、アクセシビリティ、導線条件。
