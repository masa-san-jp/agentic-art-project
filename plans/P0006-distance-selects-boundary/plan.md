## 1. 完成像

| 項目 | 内容 |
| --- | --- |
| experience sequence / encounter | 入場者は停止線の手前で、透明面の向こうにある4枚以上の新規線画を見つける。, 近づいても手が届かず、見ることと触れないことの差が自分の身体へ返る。, 光の静止区間に滞在すると、作品と自分の距離そのものへ注意が留まる。 |
| position | 作品面から450mm以上手前の停止線に立ち、幅1200mm以上の導線から見る。 |
| first_seconds | 透明面の向こうに、歪んだ線と低彩度色のパネルが見える。 |
| after_30s | 暖色光の周期が一度変化し、静止区間で距離の境界が意識される。 |
| after_3min | 介入せずに滞在する時間と、自分の身体位置が作品の一部として残る。 |

## 2. テーマ

| 項目 | 内容 |
| --- | --- |
| field | 近さ・休止・非接触の鑑賞設計 |

| difference | 休止や健康管理を説明・数値化せず、視線を通し手を止める距離そのものを作品化する。 |
| why_now | 休養・睡眠が測定と支援の対象になる現在、休む時間を効果ではなく注意の持続として問い直すため。 |

## 5. 調査の要約

| 項目 | 内容 |
| --- | --- |
| questions | 表現主義が象徴主義から受け継いだ内面化・歪曲の方法は、近接しても介入できない鑑賞距離をどのように構成できるか。, 睡眠・休息・健康管理をめぐる現在の成長トレンドは、近さ・注意・介入しないことをどのように扱い、どんな反証を持つか。, 鑑賞者を作品へ近づけながら触れる・操作することは許さず、視線と身体距離の変化だけを成立させる展示方法は何か。 |
| what_was_read | 30件の公開一次資料（美術館の表現主義・版画技法・鑑賞ガイド、厚生労働省の睡眠・休養ガイド）を読み、原文・画像の転載をせず要点とURL・ハッシュだけを台帳化した。 |
| what_came_out | 表現主義の内面化は図像引用ではなく歪曲・平坦化・色・線へ移せる。睡眠・休養は健康管理の対象だが作品は効果を主張せず、透明面・停止線・光の静止区間で非接触の近さを構成する。 |
