# 距離が選ぶ境界 — 近づいても触れない休止の場

近づくほど見える。しかし、手は届かない。

透明面の向こうに置かれた複数の線画、鑑賞者側の停止線、低照度の暖色光を組み合わせ、距離をアクセスの近さではなく、注意が留まる条件として扱う制作プランです。休止や睡眠を健康効果として説明・数値化せず、鑑賞者が自分の身体位置と「介入しない近さ」に気づく場をつくります。
