# 作品

Agentic Art の作品と制作記録の一覧です。

作品は一件につき一つのディレクトリで管理します。各作品のディレクトリ名は `W0001-short-slug` の形式とし、紹介を `README.md`、制作記録を `record.md` に記載します。作品固有の画像、映像、音声、公開可能な制作スクリプトは、その作品の `media/` に置きます。

現時点では、公開可否と権利状態の確認が完了した作品のみを掲載します。制作プランとの関係は、個別作品の `metadata.yaml` と本文のリンクで示します。

全件の機械可読一覧は [`index.yaml`](index.yaml) を参照してください。
